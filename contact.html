Proposer une fonctionnalité

Une idée, un aéroport manquant, un horaire qui paraît faux. Tout retour est utile.

Comment ça marche. SkySearch est un site statique, sans serveur pour recevoir un message. Ce formulaire met votre proposition en forme et ouvre une issue pré-remplie sur le dépôt GitHub du projet. Rien n'est envoyé avant que vous validiez la création sur GitHub, et vous pouvez tout relire d'ici là. Un compte GitHub est nécessaire, il est gratuit. Sans compte, utilisez Copier le texte et transmettez-le comme vous voulez.

Quatre caractères minimum.

Dix caractères minimum. Soyez concret, c'est ce qui rend une demande traitable.

Attention : une issue GitHub est publique. N'indiquez rien que vous ne souhaitez pas voir en ligne, et pas d'adresse personnelle.

Aperçu

Ce qui sera transmis, exactement.

Ce qui aide le plus

Un aéroport manquant
donnez son code IATA et sa ville. La liste actuelle indique ce qui est déjà couvert.
Un horaire douteux
donnez le numéro de vol affiché et ce qui vous paraît faux. Notez que les horaires de la base sont générés et ne reflètent pas les programmes réels, c'est une limite connue.
Un dysfonctionnement
indiquez votre navigateur, votre appareil, et la recherche exacte qui pose problème. Un lien de résultat suffit souvent, il contient tous les paramètres.
Une fonctionnalité
décrivez le besoin plutôt que la solution. « Je ne sais pas quelles compagnies desservent cette ligne » est plus exploitable que « ajoutez un filtre par compagnie ».

Demandes déjà écartées

Inutile de les proposer, les raisons sont documentées sur la page Objectif : affichage des prix, réservation, calcul de correspondances, carte de suivi en direct.
